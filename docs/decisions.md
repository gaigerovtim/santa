# Решения по ТЗ версии 1

Уточнения к `docs/spec-v1-site.md`, принятые 17.11.2026.

1. **Перегенерация превью** заново делает только `frameA`. `frameB` генерируется после оплаты, в задаче очереди `video`. Поэтому превью-задача выполняет шаги `prepareRoomPhoto` и `editFrame frameA`, а видео-задача — `frameB`, `clip`, `final`.
2. **Ручное одобрение.** `MANUAL_APPROVAL` в `.env` задаёт начальное значение. Переключатель в админке сохраняет новое значение в базу (таблица настроек), и дальше действует оно. В e2e-тестах одобрение выключено.
3. **Реквизиты, контакты, адрес отправителя** пока заглушки, собранные в `config/site.ts` (`MAIL_FROM` по-прежнему берётся из `.env`).
4. **Брошенные загрузки.** Фото без заказа старше 24 часов удаляет ежедневная задача очистки.
5. **Файлы-заглушки** (`frame-example.jpg`, `clip.mp4`, `silhouette.png`, `steps-bells.wav`) генерируются временно, пока нет настоящих. Замена — положить свой файл с тем же именем.
6. **`spec-stage1.md`** пока нет; промпты в `config/prompts.ts` — черновые, заменяются, когда файл появится.
